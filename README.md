## ⚓ Features & Theming

The entire site has been designed as a voyage across the Grand Line:

- **Wanted Poster Hero:** A custom CSS Wanted Poster frame featuring a live bounty counter that counts up to ∞ BERRY.
- **Captain's Log (About):** An aged parchment panel layout that treats my background (education and early career) as an origin story arc.
- **Haki Ability Board (Skills):** RPG-style stat bars that fill up on scroll, mapped to One Piece power systems (e.g., Observation Haki = AI & Digital Tools).
- **Voyage Log (Experience):** A vertical timeline detailing my professional "arcs" from East Blue to the New World.
- **Bounty Board (Projects):** A grid of Wanted Poster cards with 3D lift effects, aged texture overlays, and "Legendary" stamps for award-winning projects.
- **Devil Fruit Unlocks (Certifications):** Ability cards with glowing hover effects and animated shimmers.
- **Transponder Snail (Contact):** A deep-ocean terminal UI featuring typewriter text effects and ship signal flags for social links.

## 🌊 Technical Details

This project proves you don't always need React or heavy frameworks to build something highly interactive and beautiful.

- **Zero Dependencies:** No Bootstrap, Tailwind, React, or jQuery.
- **Pure CSS Animations:** Extensive use of `@keyframes` for the waving flags, floating ship silhouettes, mist particles, glow pulses, and the custom Log Pose compass cursor.
- **Intersection Observers:** Vanilla JavaScript `IntersectionObserver` handles all the scroll-triggered stagger-fade animations and dynamic number counters.
- **Responsive Design:** Fully fluid layouts utilizing CSS Grid and Flexbox to ensure the site looks flawless on mobile devices.
